# NoctReed

守夜人口琴（Vigil Harmonica）自动演奏工具，通过 Android 无障碍服务模拟手势点击游戏内按键。

## 工作原理

1. **简谱解析**：内置解析器支持数字简谱，识别高低音点、升降号（# / b）、延音线（-）、乐句分隔（|）与换行。
2. **无障碍手势注入**：利用 `AccessibilityService.dispatchGesture()` 在屏幕上模拟点击，按校准坐标逐个触发游戏内按键。
3. **音区与半音切换**：演奏前自动切换到目标音区（低音 / 中音 / 高音），半音按键独立切换。
4. **BPM 实时调速**：BPM 保存在状态总线（StateFlow），悬浮窗加减按钮实时修改，播放循环每个事件都重新读取当前值。

## 功能

- 粘贴数字简谱直接演奏
- 导入 .txt 乐谱 / .mid 单旋律 MIDI 文件（自动转简谱 + 提取 BPM）
- 乐谱库：保存 / 重命名 / 删除 / 切换，随曲保存 BPM
- 悬浮窗控制：播放 / 暂停 / 停止 / 切换乐谱 / 校准 / BPM 调速，可折叠可拖动
- 引导式按键校准：按提示依次点击 12 个键位（8 音符 + 4 调性），坐标存入 SharedPreferences
- Material You（莫奈取色）浅色主题

## 乐谱格式规范
本项目采用**数字简谱（Numbered Musical Notation）**，解析规则与演奏行为如下。
完整、无歧义的形式化规范另见 [SCORE_FORMAT.md](SCORE_FORMAT.md)。

### 速查表（Quick Reference）

| 写法 | 含义 |
|---|---|
| `1` `2` `3` `4` `5` `6` `7` | 中音区 do–si |
| `i` 或 `8` | 中音区高音 do（第 8 级） |
| `.5` | 低音区 sol（前缀 `.` = 降调） |
| `1.` | 高音区 do（后缀 `.` = 升调） |
| `i.` | 高高音 do（C7，升调 + i） |
| `.i` | 降八度 i（低音区 do，C5，与中音 `1` 相差八度） |
| `#4` / `♯4` | 升半音 fa |
| `b7` / `♭7` | 降半音 si |
| `5-` | 延长一拍（多个 `-` 继续延长） |
| `5_` 或 `5/` | 八分音符（1/2 拍） |
| `5__` 或 `5//` | 十六分音符（1/4 拍） |
| `5_.` / `5/.` | 附点八分音符（3/4 拍） |
| `5__.` / `5//.` | 附点十六分音符（3/8 拍） |
| `0` | 休止符（可跟 `-`/`_`/`__` 调整时值） |
| `|` 或换行 | 乐句分隔（仅用于显示） |
| `bpm=120` | 变速指令，演奏到该处实时切换 BPM |
| 行尾 `$歌词` | 歌词注释，随乐句在悬浮窗显示 |

> 等音说明：`i`（中音区第 8 级）与 `1.`（高音区 do）乐理同音，均为 C6；`.i`（降调 + i）为 C5，比中音 `1` 低一个八度。

### 基本音级与音区

- **基本音级（Degree）**：`1 2 3 4 5 6 7` 对应唱名 do re mi fa sol la si，即 C 大调自然音阶的七个音级；`8` 或 `i` 表示高音 do，与 `1-7` 同级，同样支持升降调与半音。
- **低音区（Lower Register）**：数字前加低音点，如 `.5` 表示低音 sol。对应游戏内"低音"调性键。
- **中音区（Natural Register）**：不加任何点号。对应"中音"调性键。
- **高音区（Higher Register）**：数字后加高音点，如 `1.`。对应"高音"调性键。`i` 与其他音级规则一致：裸写 `i` 为中音区第 8 级（高音 do，C6），`i.` 表示再升八度（高高音 do，C7），`.i` 表示降八度（C5）。

三个音区**互斥切换**：播放引擎在遇到跨区音符时，先按下对应调性键，等待约 120ms 切换间隙，再触发音符键。

### 半音（Accidentals）

- **升半音（Sharp）**：`#4` / `♯4` 表示 fa 升高半音。
- **降半音（Flat）**：`b7` / `♭7` / `B7` 表示 si 降低半音。
- 升降记号仅作用于紧随其后的单个音符，不延续。
- 游戏内通过独立的"半音"按键触发，引擎在触发音符前自动按下。

### 时值与延长（Duration & Ties）

时值以**拍（beat）**为单位，基准拍长由 BPM 决定（`拍长ms = 60000 / BPM`）。内部以 tick 计量：**1 拍 = 16 tick**，最小可表达时值为 1/4 拍（十六分音符，4 tick）。

| 记法 | 含义 | 时值 |
|------|------|------|
| `5` | 四分音符 | 1 拍 |
| `5_` 或 `5/` | 八分音符 | 1/2 拍 |
| `5__` 或 `5//` | 十六分音符 | 1/4 拍 |
| `5_.` 或 `5/.` | 附点八分音符 | 3/4 拍 |
| `5__.` 或 `5//.` | 附点十六分音符 | 3/8 拍 |
| `5-` | 二分音符 | 2 拍 |
| `5--` | 附点二分音符 | 3 拍 |
| `5---` | 全音符 | 4 拍 |
| `0` | 四分休止符 | 静默 1 拍 |
| `0_` | 八分休止符 | 静默 1/2 拍 |
| `0-` | 二分休止符 | 静默 2 拍 |

延音线 `-` 的两种合法位置：
1. **尾随音符**：直接附加在数字后，如 `3--`（该音符共 3 拍）。
2. **独立记号**：`-` 单独作为一个 token，延长**前一个音符/休止符**一拍。

分时值记号 `_`（或 `/`）只缩短基础拍，不影响 `-` 延音部分，可叠加使用，如 `5_-` = 八分音符 + 1 拍延音 = 3/2 拍。

**延长音的演奏行为**：引擎只在音符开始时点击一次按键，后续时值由静默等待构成。这模拟了真实吹奏中的**连音（Legato）**——按键按下后保持发音，不重复触发。

> **十六分音符的糊音/吞音风险**：受 Android 无障碍手势调度与协程计时精度限制，高 BPM（≥ 120）下十六分音符的按下保持时长会被压缩到 30–60 ms，相邻音容易粘连（糊音），极端情况下会出现丢击（吞音）。连续十六分音符段落建议 BPM ≤ 100。

### 歌词注释（Lyrics）

行内 `$` 之后到行尾的全部内容为歌词注释，不产生音符。歌词与所在行的乐句一一对应，演奏到该乐句时悬浮窗乐句位优先显示歌词：

```
1 1 5 5 | 6 6 5- $ 一闪一闪亮晶晶
4 4 3 3 | 2 2 1- $ 满天都是小星星
```

### 变速指令（bpm=）

独立 token `bpm=x`（如 `bpm=140`）可写在乐谱任意位置，演奏推进到该处时立即切换 BPM（范围 30–300），不占时值。

### 连音与吐音的区分

- **连音 / 延长音（Tied / Sustained note）**：使用 `-` 延长的音，只按一次键，靠等待撑满时值，听感为一个连贯长音。
- **吐音（Tongued / Repeated note）**：连续写出相同音级，如 `5 5`，解析为两个独立事件，引擎**点击两次**，模拟真实口琴的吐音奏法，每个音有独立音头。

### 乐句分隔（Phrase Boundaries）

竖线 `|`、换行符、回车符均视为**乐句（Phrase）边界**。乐句信息有两个用途：

1. 悬浮窗实时显示"第 x / y 句"及当前乐句原文。
2. 乐句切换时可作为用户视觉参考点。

**乐句边界不影响时值**——跨乐句的音符时值仍按自身拍数正常流逝，`5 | 5-` 中两个 `5` 独立计算，前 1 拍 + 后 2 拍，不因竖线产生额外停顿。

### 完整示例

```
1 1 5 5 | 6 6 5- | 4 4 3 3 | 2 2 1-
```

对应《小星星》前四乐句。每句四拍，`5-` 表示该音符持续 2 拍（二分音符），其余为四分音符。

## 使用步骤

1. 安装 APK，打开应用
2. 开启**无障碍服务**（设置 → 无障碍 → NoctReed）
3. 授权**悬浮窗权限**（允许显示在其他应用上层）
4. 进入游戏守夜人口琴界面
5. 点悬浮窗上的**校准**，按提示点击游戏内按键（共 12 个）
6. 粘贴或载入乐谱，点**开始**

## MIDI 导入要求

- 单旋律，无和弦（多个同时发音的音符只取最高音）
- 音域须在 **G4 — ♯C7** 之间（低音 5 ～ ♯i.）
- 自动检测 BPM 并写入

## 可吹音域（基于 12 键机制验证）

游戏内口琴共 12 个按键：8 个音符键（1 2 3 4 5 6 7 i）+ 4 个调性键（低音 / 自然音 / 高音 / 半音）。`i` 与 1–7 同级、共用同一套调性规则。基准音域为中音 C5–B5，全部可吹音如下（含半音键组合）：

| 调性 | 简谱 | 音名（自然 / 升半音） |
|------|------|----------------------|
| 低音 | `.1` `.2` `.3` `.4` `.5` `.6` `.7` | C4/♯C4 · D4/♯D4 · E4 · F4/♯F4 · G4/♯G4 · A4/♯A4 · B4 |
| 中音 | `1`–`7` | C5/♯C5 · D5/♯D5 · E5 · F5/♯F5 · G5/♯G5 · A5/♯A5 · B5 |
| 中音 | `i` | C6 / ♯C6（与 `1.` 等音） |
| 高音 | `1.`–`7.` | C6/♯C6 · D6/♯D6 · E6 · F6/♯F6 · G6/♯G6 · A6/♯A6 · B6 |
| 高音 | `i.` | C7 / ♯C7（`#i.`） |

- **上限为 ♯C7（MIDI 97），下限为 C4（MIDI 60）**，完整覆盖 C4–♯C7。
- **半音键只升不降**：降半音记作"降调 + 升半音"（如 `b2` 等效于 `.#2` 即 C♯4）；但 **C4（`.1`）不可再降**——`.1` 没有更低的半音可用，`b1` 与 `.b1` 均无法演奏。
- MIDI 导入器按此范围校验，超域音符会被拒绝并提示。
